# Within Reach Subtitle Studio 0.1.0 Beta 3

## 新增

- 支持完整时间线透明字幕视频导出；
- 支持当前 Segment 导出；
- 支持选择多个 Segment 并分别导出；
- 支持全部 Segment 分别导出；
- 支持 Segment 本地零时间映射；
- 支持跨 Segment 边界 Cue 裁切；
- 支持 qtrle 和 ProRes 4444 Alpha；
- 支持 Segment 取消、Recovery 和缓存复用。

## 修复

- Segment 创建不再要求绑定参考视频；
- 修复 Selected Segments 实际仍渲染完整工程 Cue 的问题；
- 修复 Exact Patch 未携带 `requested_cue_ids` 的问题；
- 修复 Patch 缓存身份未校验 Cue 集合的问题；
- 修复 Selected、Current 和 Full Timeline 切换后的 Readiness 状态；
- 修复签名 App 无法加载 DaVinci 官方 `fusionscript.so` 的问题；
- DaVinci Loader 现在只加载官方规范路径并验证签名。

## DaVinci Resolve

- 支持自动创建完整工程字幕时间线；
- 已通过真实 Media Pool 和字幕轨道验证；
- Segment 范围目前支持透明字幕 MOV 分段导出；
- DaVinci Resolve 自动时间线创建暂时仍以完整工程为单位；
- Segment 时间线自动创建计划在后续版本提供。

Segment范围目前支持透明字幕MOV分段导出。DaVinci Resolve自动时间线创建暂时仍以完整工程为单位；Segment时间线自动创建计划在后续版本提供。

## 系统要求

- Apple Silicon Mac；
- macOS 26.0 或更高；
- 使用 DaVinci 时间线功能时需要安装并启动 DaVinci Resolve；
- 不需要用户安装 Python、Homebrew 或 FFmpeg。
