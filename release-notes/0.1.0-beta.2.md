# Within Reach Subtitle Studio 0.1.0 Beta 2

## 主要修复

- 修复首次启动或新工程未绑定参考视频时，字幕 Preview 无法完成的问题；
- 字幕 Preview 不再依赖参考视频；
- 修复异步 Font/Style 上下文初始化与首次 Preview 之间的竞态；
- 移除参考视频后不再恢复旧视频路径。

## 新增能力

- 集成 Sparkle 自动更新；
- 支持应用内手动检查更新；
- 使用 HTTPS 公开 Feed；
- 使用 Sparkle EdDSA 签名验证更新包。

## Beta 1 用户说明

Beta 1 没有嵌入 Sparkle Feed。

已经安装 Beta 1 的用户需要手动下载安装 Beta 2 一次。

从 Beta 2 开始，未来版本可以通过应用内“检查更新”升级。

## 系统要求

- Apple Silicon Mac；
- macOS 26.0 或更高；
- 不需要用户安装 Python、Homebrew 或 FFmpeg。

## 安装

打开 DMG，将应用拖入 Applications。

## 安全

- Developer ID Signed；
- Hardened Runtime；
- Secure Timestamp；
- Apple Notarized；
- Stapled Ticket；
- Gatekeeper Accepted；
- Sparkle EdDSA Signed Update。
