# Within Reach Subtitle Studio 0.1.0 Beta 4 Build 9 — Windows

Build 9 enables the signed Windows online-update channel for the existing
Windows Beta. It uses WinSparkle 0.9.4, numeric Build Number comparison, the
independent production Windows appcast, and a Windows-only EdDSA trust key.

## Update scope

- Product version: `0.1.0`
- Display version: `0.1.0 Beta 4`
- Build: `9`
- Channel: `beta`
- Edition: `Windows Beta`
- Default feed: `appcast-windows.xml`
- Installer arguments: `/SILENT /SP- /NOICONS`

No Cue Renderer, Geometry, Sparse, Manifest, Recovery, font, FFmpeg, or CUDA
contract was changed for this release.

## Local acceptance

- Packaged startup and WinSparkle load passed.
- Main-window GUI smoke and zero-console-window checks passed.
- Fast SBS Preview rendered successfully.
- Three-Cue CPU Exact Patch generation passed.
- Short qtrle Sparse export and deep validation passed without fallback.
- Inno Setup 7.0.2 compiled successfully and its help UI opened.
- The installer was verified with the Windows EdDSA signature.

This Windows release remains a prerelease until the real Build 9 to Build 10
online-update workflow is accepted. The installer has an EdDSA update
signature but is not Authenticode-signed, so Windows SmartScreen may identify
the publisher as unknown.
