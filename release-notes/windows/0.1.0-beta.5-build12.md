# Within Reach Subtitle Studio 0.1.0 Beta 5 Build 12

Build 12 is a Windows hotfix for Segment spatial-state persistence.

- Fixes an issue where switching back after saving spatial settings for two or
  more Segments could overwrite part of a Segment's Placement with defaults.
- Preserves each Segment's independent spatial settings, font, and font size
  across switching and close/reopen.
- Keeps pure Segment switching read-only and no longer rewrites project files.
- Prevents roll and horizontal field of view from being reset after the UI
  hydrates a Segment's saved values.
- Retains the precompiled CUDA PTX path, CPU fallback, and signed online update
  capability from the existing Windows Beta 5 build.
