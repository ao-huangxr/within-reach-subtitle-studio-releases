# Within Reach Subtitle Studio 0.1.0 Beta 4 Update Test Build 10 — Windows

Build 10 is the staging-only package used to verify the signed WinSparkle
update path from Build 9. It contains the same product source as Build 9; only
the numeric Build Number, display version, staging feed selection, and release
notes differ.

## Update-test scope

- Product version: `0.1.0`
- Display version: `0.1.0 Beta 4 Update Test`
- Build: `10`
- Channel: `beta`
- Edition: `Windows Beta`
- Feed: `appcast-windows-staging.xml`
- Installer arguments: `/SILENT /SP- /NOICONS`

This build is a prerelease and must remain on the staging feed. It is not for
ordinary users. No Cue Renderer, Geometry, Sparse, Manifest, Recovery, font,
FFmpeg, or CUDA contract differs from Build 9.

The installer has a verified EdDSA update signature but is not
Authenticode-signed, so Windows SmartScreen may identify the publisher as
unknown.
