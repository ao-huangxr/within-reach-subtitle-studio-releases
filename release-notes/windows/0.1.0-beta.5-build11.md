# Within Reach Subtitle Studio 0.1.0 Beta 5 - Windows Build 11

This prerelease formally enables NVIDIA acceleration through the bundled
precompiled `compute_75` CUDA PTX kernel.

## Requirements and fallback

- An NVIDIA GPU with a compatible driver is sufficient for the GPU backend.
- CUDA Toolkit, `nvcc`, `CUDA_PATH`, Python and NVRTC are not required.
- If the real CUDA capability probe fails, Subtitle Studio automatically uses
  the CPU compatibility backend.

## Acceptance

- Driver-only NVIDIA capability and precompiled-PTX binding passed.
- Single Cue 6K, 3 Cue 4K and Exact Patch workflows passed.
- Missing, damaged or incompatible PTX selects the CPU fallback; restoring the
  accepted package restores NVIDIA CUDA.
- Current-user installation over Build 9 preserved projects and settings.
- Start Menu launch, bundled FFmpeg/FFprobe helpers, zero terminal popups and
  uninstall project preservation passed.
- The package contains no font binaries, CUDA Toolkit, NVRTC DLLs or builtins,
  nvJitLink, CUDA headers, CUDA source, NVIDIA scientific-computing libraries
  or validation media.

## Windows signing notice

This installer is not currently Authenticode-signed. Windows may therefore
show an Unknown Publisher dialog or a Microsoft Defender SmartScreen warning.
The WinSparkle update is protected by the published EdDSA signature and the
release checksum.
