# Within Reach Subtitle Studio

Official macOS downloads and Sparkle update feed.

本仓库用于：

- 官方软件下载安装；
- Release Notes；
- Sparkle 自动更新 Feed；
- SHA256 校验；
- Build Manifest。

Within Reach Subtitle Studio 当前为 Beta 软件，仅支持 Apple Silicon，
系统要求为 macOS 26.0 或更高。发布的应用经过 Developer ID 签名和 Apple
Notarization；这不表示软件已成为稳定正式版。

源代码不在本仓库公开。Bug 反馈请使用本仓库的
[Issues](https://github.com/ao-huangxr/within-reach-subtitle-studio-releases/issues)。
